# Manual Test Case Template

Use this exact format for each test case.

ID: TC-<number>
Title: <concise, requirement-focused title>
Preconditions:
- <list preconditions>
Steps:
1. <step 1>
2. <step 2>
Expected Result:
- <expected outcome>

---

Example

ID: TC-001
Title: User can submit a valid application
Preconditions:
- User is logged in
- Application form is accessible
Steps:
1. Enter valid data in all required fields
2. Click Submit
Expected Result:
- Submission succeeds and confirmation is displayed
