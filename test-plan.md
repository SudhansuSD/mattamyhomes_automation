## CI / CD

- **GitHub Actions workflow:** `.github/workflows/playwright.yml`
- CI runs headless on the Chrome project; `@ci`-tagged tests target the CI smoke path.

## Assumptions

- Target environment & country are configured via `ENV` / `COUNTRY` env vars.
- The site under test is reachable from the execution host.
- Location-specific data (markets, communities, plans) comes from `config/locations`.

## Out of Scope

- Native mobile app testing (only mobile *web* via Appium is covered).
- Backend / API contract testing.
- Performance, load and security testing.
- Actual lead-form submissions (forms are validated without submitting).
